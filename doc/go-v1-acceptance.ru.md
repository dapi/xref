# Критерии готовности Go xref 1.0

Цель этой версии — полезный локальный индекс Ruby/Rails-проекта, который отвечает
на вопросы о коде и возможных обращениях к таблицам без загрузки приложения.
Это самостоятельный офлайн-инструмент, а не перенос всех 41 команды исходного
Ruby xref. Команды, которым нужны production-логи или живые данные, не входят
в этот выпуск. Исходный проект и его автор указаны в README и лицензиях.

Выпуск готов, когда **все** условия ниже выполнены и проверены на публичных
фикстурах. Частный проект используется только для локальной проверки; его код,
данные и маршруты не входят в публичный репозиторий или отчёт CI.

1. **Самостоятельный запуск.** Документированы сборка и запуск из другого
   каталога. Для `refresh`, `where`, `find`, `blind`, `audit`, `coverage`,
   `route`, `trace` и `callers` не требуются загрузка Rails, Bundler, запущенная
   БД или сеть. Схема по умолчанию читается из локального `db/structure.sql`;
   подключение к PostgreSQL возможно только по явному `--schema ...=pg:...`.
   Индекс находится вне проекта, его путь виден в `refresh`/`audit`.
2. **Доказуемые ответы.** SQL и типовые прямые вызовы ActiveRecord, scope и
   однозначные связи моделей дают ссылки на таблицы и колонки с файлом, строкой
   и уровнем уверенности. Неоднозначные получатели, метапрограммирование и
   неподдержанные переходы остаются видимыми пробелами. Отсутствие цепочки
   никогда не объявляется доказательством отсутствия обращения к БД.
3. **Навигация от маршрута.** `route`, `trace` и `coverage` связывают статически
   распознанные маршруты с локальными действиями, вызовами, scope и шаблонами.
   Публичные тестовые проекты проверяют как найденную цепочку, так и случаи
   внешнего родителя, динамического вызова и страницы без найденной ссылки.
4. **Актуальность и границы данных.** Изменение исходника, схемы или версии
   анализатора обновляет нужные записи; повторный запрос без изменений их не
   пересканирует. Индекс и временные файлы доступны только владельцу. Никакой
   исходный код анализируемого проекта не отправляется вовне.
5. **Проверяемая поставка.** `go test ./...`, `go vet ./...` и сборка проходят в
   CI. README показывает Go-команды как основной путь для этого форка и честно
   отделяет их возможности от сохранённого Ruby-движка. Проверка на крупном
   Rails-проекте подтверждает запуск без Rails/БД, полезные цепочки и
   объяснимые пробелы; результат фиксируется без публикации частного кода.

После выполнения условий выпускается версия `v1.0.0` с краткими примерами и
известными ограничениями. Новые пожелания после этого относятся к следующим
версиям, если не обнаруживают нарушение условий выше.
